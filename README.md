#### Requirements

base packages: 

Git

neovim

tree-sitter-cli

gcc (for treesitter-cli)

lsp packages:

rust-analyzer & rust-src

lua-language-server

bash-language-sever

clangd 

#### Getting Started

Clone the repo:

```shell

git clone https://github.com/mlndcontrol/nvim-config ~/.config/nvim

```

Remove the .git folder:

```shell

rm -rf ~/.config/nvim/.git

```

Start nvim:

```shell

nvim

```
